# 🐧 Pingo — 2D Platformer

> ⚠️ Work in progress

A 2D platformer built in **Unity (C#)** where you play as Pingo, a penguin collecting fish coins across three levels of increasing difficulty.

## 🎮 Gameplay

Collect **5 fish coins** per level to unlock the exit door and progress to the next stage. Watch out for dead zones!

### Controls

| Key | Action |
|-----|--------|
| `←` / `→` | Move |
| `Space` | Jump |
| `Space` (on wall) | Wall jump |

## ✨ Features

- Wall sliding & wall jumping
- Horizontal and vertical moving platforms
- 3 difficulty levels — Easy, Normal, Hard
- Fish coin counter with sprite-based UI
- Fade in / out transitions between scenes
- Camera follow

## 🛠️ Built With

- **Unity**
- **C#**
